호재맵(hojaemap.kr) · 시행일 2026-09-10

호재맵은 공개된 공식 데이터에서 개발 신호를 모아 지도로 보여 주는 개인 운영 서비스입니다. 회원가입이 없고 이름·연락처를 받지 않습니다. 아래에 적은 것이 저희가 가진 전부입니다.

알림을 켤 때 브라우저가 발급한 알림 주소와 키, 지켜보기로 고른 단지·사업·지역 목록 고른 대상에 새 신호가 잡히면 알림 발송

방문자 구분 코드는 브라우저에 저장되는 무작위 16자리 문자열입니다. 이름·이메일·전화번호와 연결되지 않으며, 브라우저 저장소를 지우면 새로 만들어집니다. 이름·이메일·전화번호·주민등록번호는 어떤 경우에도 수집하지 않습니다.

지도에서 고른 집·직장 위치, 비교 목록, 화면 설정은 내 브라우저에만 저장되며 서버로 보내지 않습니다. 다만 알림을 켜면 그때 고른 지켜보기 목록은 알림 발송을 위해 서버에 저장됩니다.

2. 얼마나 보관하나

  • 방문 기록: 180일 뒤 자동 삭제
  • 의견·알림 구독 정보: 목적을 다할 때까지. 알림을 끄면 구독 정보는 지워집니다.
  • 법령이 보관을 요구하는 경우 그 기간을 따릅니다.

4. 이용자가 할 수 있는 것

  • 알림 끄기 — 사이트의 알림 설정에서 끄면 구독 정보가 삭제됩니다.
  • 브라우저 저장 지우기 — 방문자 구분 코드와 내 설정이 모두 사라집니다.
  • 열람·삭제 요청 — 아래 연락처로 요청하시면 확인 후 처리하고 결과를 알려 드립니다.

회원가입이 없어 본인 확인 수단이 제한적입니다. 삭제를 요청하실 때는 방문자 구분 코드를 함께 알려 주시면 해당 기록을 특정할 수 있습니다. 코드는 브라우저 개발자도구에서 hojae_vid 값으로 확인됩니다.

5. 안전조치

  • 모든 통신은 HTTPS로 암호화됩니다.
  • 기록 조회는 운영자 전용 화면에서 별도 인증으로만 가능합니다.
  • 수집 항목을 최소로 유지하고, 보관 기간이 지난 방문 기록은 자동으로 지웁니다.
